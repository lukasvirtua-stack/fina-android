# FINA Android

Aplicativo Android de teste para abrir a FINA atual em um Trusted Web Activity / Custom Tab seguro.

- Produção: https://fina-html-v14.vercel.app/
- Backend: o mesmo Supabase/Pluggy usado pela versão web.
- Não duplica regras financeiras nem mantém banco de dados separado.
- O APK gerado por GitHub Actions é de teste (debug) para instalação direta.
